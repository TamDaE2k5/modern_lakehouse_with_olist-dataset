  ### 1. Bảng danh sách các cổng xuất ra ngoài (Host Ports)

	Cổng trên Host      | Service container        | Biến cấu hình (trong .env) | Cổng gốc bên trong container | Mục đích / Giao thức
  --------------------------|--------------------------|----------------------------|------------------------------|-------------------------------------------------------------
             9000           | minio                    | MINIO_API_PORT             |             9000             | MinIO S3 API (truy cập lưu trữ S3, PySpark S3A, Ingestion)
             9001           | minio                    | MINIO_CONSOLE_PORT         |             9001             | MinIO Web Console (giao diện web quản lý bucket & user)
             8082           | trino                    | TRINO_PORT                 |             8080             | Trino SQL UI & API (truy vấn SQL dữ liệu Lakehouse Iceberg)
             8083           | airflow-webserver        | AIRFLOW_PORT               |             8080             | Airflow Web UI (quản lý, kích hoạt và theo dõi các DAGs)
             8084           | spark-master             | SPARK_PORT                 |             8080             | 
             8085           | spark-worker             | SPARK_PORT                 |             8080             | 
             8088           | superset                 | SUPERSET_PORT              |             8088             | Superset Web UI (Business Intelligence, báo cáo biểu đồ)
             9090           | prometheus               | PROMETHEUS_PORT            |             9090             | Prometheus UI (thu thập metrics và kiểm tra alert rules)
             3000           | grafana                  | GRAFANA_PORT               |             3000             | Grafana UI (dashboard trực quan hóa giám sát toàn hệ thống)

  │ Note
  │ Tất cả các cổng trên đều được gắn cố định với địa chỉ 127.0.0.1 (ví dụ: 127.0.0.1:8083:8080), đảm bảo an toàn bảo mật, không bị lộ ra ngoài mạng LAN hoặc Public IP của bạn.
  │ Nếu cần đổi cổng khi bị trùng, bạn chỉ cần chỉnh biến tương ứng trong file .env.
  ──────
  ### 2. Các cổng NỘI BỘ (Không xuất ra ngoài host)

  Các cổng sau chỉ giao tiếp nội bộ giữa các container trong mạng lakehouse-internal:

  • 5432: PostgreSQL (chỉ Airflow, Superset và Trino Iceberg Catalog kết nối nội bộ)
  • 7077: Spark Master RPC (Spark Worker kết nối tới Master)
  • 8080 / 8081: Spark Web UI nội bộ
  • 9115: Blackbox Exporter (Prometheus scrape nội bộ)
  • 8000: Pipeline Metrics Exporter (Prometheus scrape nội bộ)
